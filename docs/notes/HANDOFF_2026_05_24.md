### Amélioration #6 — Patterns répétés (Tier 2)

Nouveau modèle `repeat` dans le pipeline `estimateRank` :
- `aaaa`, `111111` → répétition pure
- `abababab`, `12341234` → cycle répété
- `1234`, `abcd`, `zyxw` → séquence croissante/décroissante
- `aaa123` → composition (repeat ≥ 3 chars + reste)
- `aa123` → null (< 3 chars, tombe en brute/mask)

**Formule :**
- Répétition/cycle : `charset^len_motif × 2^len_total` (Wheeler 2016)
- Séquence : `charset × 2` (nb de points de départ × 2 directions)
