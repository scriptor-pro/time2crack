Où en est vraiment main face à codex-site-publish ?

Le site en production (time2crack.eu) ne tourne pas sur la branche où se fait le travail. Voici ce que ça change et trois façons d'y répondre.

Le worktree CrackDate-publish pointe en HEAD détachée sur le commit cb69bc3d, et son index.html est strictement identique à ce que sert time2crack.eu — confirmé par diff direct. Ce commit vit sur codex-site-publish.

Ce n'est pas une fourche parallèle : main est un ancêtre direct de codex-site-publish. Le fork date du 26 août ; main n'a rien produit depuis que codex-site-publish n'ait déjà. Le vrai sujet est donc un flux de release à sens unique et manuel — le travail avance sur main, puis quelqu'un (ou un agent nommé « codex ») le porte et le complète côté publish, sans que ce sens ne s'inverse jamais.

Constat

Certains des 80 commits sont des retraits (ML/ONNX absent faute de fichiers, chemins CDN corrigés) — un merge naïf vers main pourrait soit réintroduire du code cassé, soit écraser du travail en cours si mal résolu.

Trois options

Classées par coût d'entrée croissant. Le risque porte sur la santé du dépôt, pas sur la difficulté d'exécution.

Option Ce que ça implique Coût immédiat Risque Convient si…
A · Comprendre le flux Cartographier comment et par qui les 80 commits sont produits — manuel, script, agent dédié. Faible Aucun On ne sait pas encore si ce split est délibéré ou une dérive.
B · Réconcilier Merger ou rebaser codex-site-publish vers main pour n'avoir qu'une source de vérité déployable. Moyen–élevé Élevé L'objectif est la santé du dépôt à long terme, avec itérations fréquentes à venir.
C · Implémenter direct Poser le design de conversion (badges de confiance, alerte HIBP à deux niveaux, tableau hiérarchisé) directement sur codex-site-publish. Faible Dette croissante La priorité est un résultat visible en production maintenant.

Recommandation

Commencer par A : coût quasi nul, et sa réponse détermine si B est praticable proprement ou si C reste la seule option réaliste à court terme.

Sans cette clarté, tout ce qui atterrit sur main — dont fix/methode-pages en cours — continue de s'accumuler sans jamais atteindre time2crack.eu.
