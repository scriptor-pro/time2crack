# Time2Crack v2.1 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire Time2Crack v2.1 avec Eleventy (11ty) et app.js découpée en modules ES, hero section claire, responsive, WCAG 2.1 AA.

**Architecture:** Site statique généré par 11ty à partir de templates Nunjucks. L'app.js monolithique (6 604 lignes) est découpée en modules ES natifs chargés via `<script type="module">`. Les fichiers ML/wordlists/calibrations existants sont réutilisés tels quels, sans modification.

**Tech Stack:** Eleventy 3.x, Nunjucks, ES Modules natifs (pas de bundler), CSS vanilla, WCAG 2.1 AA.
