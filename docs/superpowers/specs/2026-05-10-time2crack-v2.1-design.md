## 1. Périmètre et objectifs

Time2Crack v2.1 est une réécriture complète du site time2crack.eu — estimateur de temps de crack de mots de passe. Il remplace la v1 (GitHub Pages, `main`) et sera déployé sur YunoHost (`manderley.noho.st`).

**Objectifs :**
- Architecture modulaire maintenable (ES6 modules bundlés par esbuild)
- 126 pages HTML statiques (14 pages × 9 langues) générées par Eleventy
- WCAG 2.1 AA strict
- Zéro dépendance runtime (vanilla JS)
- v1 reste opérationnelle sur `main` pendant tout le développement

**Contraintes :**
- La v1 sur `main` ne doit pas être modifiée
- Aucune donnée utilisateur transmise (HIBP via k-anonymity uniquement)
- Wordlists (~32 MB) servies via CDN Bunny, jamais commitées
- Corpus ML (~683 MB) jamais commités

## 6. Architecture JavaScript

### Règles d'architecture

| Règle | Détail |
|-------|--------|
| Taille max | 300 lignes par fichier |
| `core/` | Zéro dépendance interne, fonctions pures uniquement |
| Sens des imports | `ui/` → `core/`, `attacks/`, `services/` ; jamais l'inverse |
| Null-guards | Centralisés dans `utils/dom.js` |
| Effets de bord | Uniquement dans `ui/` et `main.js` |

### `utils/dom.js`

```js
export const qs = (sel, root = document) => root.querySelector(sel);
export const qsa = (sel, root = document) => [...root.querySelectorAll(sel)];
export const on = (el, evt, fn) => el?.addEventListener(evt, fn);
```

```js
import { initInput } from './ui/input.js';
import { initResults } from './ui/results.js';
```

## 9. Stratégie de tests

### Trois niveaux

| Niveau | Outil | Cible | Déclenchement |
|--------|-------|-------|---------------|
| Unitaire (TDD strict) | Vitest | `core/`, `attacks/`, `services/` | pre-commit + CI |
| UI / a11y | axe-core + Playwright | Pages dans `dist/` | `npm run test:e2e` |
| Build integration | Script shell | 126 fichiers HTML | `npm run build` |

### Règles TDD

- Test écrit **avant** le code pour tout fichier `core/` et `attacks/`
- Couverture 100% branches sur ces modules
- `hibp.js` : mock fetch, vérifier k-anonymity (hash tronqué à 5 chars)
- `idb-cache.js` : tester avec `fake-indexeddb`

### 3 golden paths Playwright

1. **Analyse** : saisir `P@ssw0rd!` → tableau résultats visible, classe `is-empty` absente, temps non vide
2. **HIBP** : saisir `password` → alerte de compromission affichée
3. **Langue** : depuis `/en/`, cliquer `FR` → redirection `/fr/`, `<h1>` en français

### Audit axe-core

```js
const pages = ['/', '/generator/', '/hibp/', '/faq/', '/about/', '/how-it-works/'];
for (const path of pages) {
  test(`axe: ${path}`, async ({ page }) => {
    await page.goto(`http://localhost:8080/en${path}`);
    const results = await new AxeBuilder({ page }).analyze();
    expect(results.violations).toEqual([]);
  });
}
```

### Test d'intégration build

```bash
HTML_COUNT=$(find dist -name "*.html" | wc -l)
[ "$HTML_COUNT" -eq 126 ] || { echo "FAIL: $HTML_COUNT fichiers (attendu 126)"; exit 1; }
```

## Décisions clés

| Décision | Choix retenu | Alternative écartée |
|----------|-------------|---------------------|
| Bundler JS | esbuild | Native ESM, IIFE |
| Granularité modules | ~15–20 modules domaine-métier | Monofichier, micro-modules |
| i18n Eleventy | Mode A : shared data + pagination | Mode B : 54 fichiers séparés |
| Hero | Éducatif avec contexte | Minimaliste |
| A11y testing | axe-core + audit manuel | pa11y, Lighthouse seul |
| Tests UI | TDD strict engine + Playwright UI | TDD sur tout, aucun test |
| Git | Branches dans repo racine | Sous-repos séparés |
| v1 pendant dev | Cohabitation (branches séparées) | Migration immédiate |
